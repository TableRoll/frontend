# D&D Campaign Management System - Technológiai Áttekintés

## 🎲 Egy Grandiózus Virtual Tabletop Platform

### Modern Full-Stack Architektúra

**Frontend - Professzionális Felhasználói Élmény:**
- ⚛️ **React 18** + **TypeScript** - Type-safe, modern UI fejlesztés
- 🎨 **Mantine UI** - Gyönyörű, professzionális komponens könyvtár
- 🗺️ **OpenLayers-kompatibilis** térképkezelés - Interaktív, zoomolható játéktérkép
- 🔄 **Zustand** - Könnyű, de erőteljes state management
- 💾 **Persisted Storage** - Automatikus adatmentés localStorage-ba

**Backend - Ipari Szintű API:**
- 🟢 **Node.js 18** + **Express** - Skálázható, gyors szerver
- 🐘 **PostgreSQL 15** - Enterprise-grade relációs adatbázis
- 🔐 **JWT Authentication** - Biztonságos felhasználói hitelesítés
- 🛡️ **Express Validator** - Input validáció és biztonság
- 📊 **Query Optimization** - Connection pooling, tranzakciók

**DevOps & Infrastructure:**
- 🐳 **Docker + Docker Compose** - Teljes konténerizáció
- 📈 **Prometheus** - Valós idejű metrika gyűjtés
- 📊 **Grafana** - Professzionális monitoring dashboard
- 🔍 **cAdvisor** - Container resource monitoring
- 📦 **Multi-stage Docker builds** - Optimalizált production build

**Biztonság & Best Practices:**
- 🔒 **Helmet.js** - HTTP security headers
- 🚦 **Rate Limiting** - DDoS védelem
- 🔑 **bcrypt** - Jelszó hash-elés
- 🌐 **CORS** konfiguráció
- 📝 **Morgan** - HTTP request logging

### Komplex Funkciók

**Játékmenedzsment:**
- ✨ Campaign rendszer - Több kampány párhuzamos kezelése
- 🗺️ Dinamikus térképek - Grid overlay, zoom, pan
- 👥 Karakter alkotás - Teljes D&D 5e támogatás
- ⚔️ Combat tracker - Initiative tracking, action economy
- 🎭 Token menedzsment - Drag & drop, HP tracking, status effects

- 🔄 Foreign key constraints - Adatintegritás
- 📅 Timestamp tracking - created_at, updated_at minden táblán
- 🔍 Indexelt keresések - Optimalizált lekérdezések

**Real-time Features:**
- 🎵 Audio player - Ambient és battle music
- 💬 Chat rendszer (tervezett)
- 🔄 Live szinkronizáció (tervezett WebSocket support)
